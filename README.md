# Agromatical

Página para cuidar un invernadero: datos de adentro (servidor del profe), clima de afuera y pronóstico (Open-Meteo), horarios de riego, login con Firebase y AgrIA.

## Cómo abrirla

Abrir la carpeta en VS Code y darle a **Go Live** (Live Server) sobre `index.html`.

Los datos de adentro del invernadero solo llegan estando conectados a la red de la escuela.
